## 整体设计风格

这是一个极简主义的个人作品集网页，采用黑白灰为主色调，具有以下特点：
- **设计风格**：简约现代、科技感、沉浸式体验
- **色彩方案**：白色背景 + 黑色文字 + 灰色装饰元素
- **字体**：无衬线字体（如 Inter、Poppins 等）
- **动画**：滚动触发的透视动画效果

## 动画与交互效果（基于视频连续帧分析）

### 1. 首页核心交互动效：黑圈透视动画（最重要）

这是整个网页最具特色的交互动效，所有动效都是**连续流畅**的，不是离散的状态切换。

#### 核心交互逻辑（连续动画）

**1. 黑圈平滑跟随鼠标**
```
用户鼠标移动 → 黑圈以缓动函数平滑跟随 → 有轻微延迟（约100-200ms）
```

- 黑色圆形元素（直径约350-400px）始终跟随鼠标移动
- 使用 `requestAnimationFrame` + 缓动函数实现平滑跟随
- 黑圈不是立即到达鼠标位置，而是有轻微的延迟和缓动效果
- 黑圈内偶尔显示关键词（如"工程师"、"Agent"等），文字会随着鼠标位置动态变化

**2. 标题文字3D透视倾斜**
```
用户鼠标移动 → 标题文字根据鼠标位置产生连续的3D透视倾斜
```

- 英文标题"HELLO, I'M Leo"会根据鼠标位置产生连续的旋转/倾斜效果
- 使用 CSS `perspective` + `rotateX`/`rotateY` 实现3D透视
- 鼠标在标题上方时，文字会朝向鼠标方向倾斜，产生立体感
- 这是一个**连续的实时计算**，不是预设的关键帧动画

**3. 透视遮罩效果**
```
黑圈移动到标题上方 → 黑圈内的区域显示对应的中文翻译
```

- 当黑圈移动到英文标题"HELLO, I'M Leo"上方时
- 黑圈内的区域会显示对应的中文翻译
- 中文翻译是**连续变化**的，根据黑圈在标题上的位置：
  - 黑圈在"HELLO"上方 → 显示"你"
  - 黑圈在"I'M"上方 → 显示"我是"
  - 黑圈在"Leo"上方 → 显示"我是龙"
- 文字切换有淡入淡出的过渡效果，不是瞬间切换

#### 技术实现（强调连续性）

```javascript
// 核心逻辑：使用 requestAnimationFrame 实现连续动画
class MagicCircle {
  constructor() {
    this.circle = document.querySelector('.magic-circle');
    this.title = document.querySelector('.hero-title');
    this.chineseTexts = ['你', '我是', '我是龙'];
    this.mouseX = 0;
    this.mouseY = 0;
    this.currentX = 0;
    this.currentY = 0;
    this.currentText = '';
    this.textOpacity = 0;
  }

  // 鼠标移动事件（捕获目标位置）
  onMouseMove(e) {
    this.mouseX = e.clientX;
    this.mouseY = e.clientY;

    // 计算文字倾斜角度（实时计算）
    const titleRect = this.title.getBoundingClientRect();
    const titleCenterX = titleRect.left + titleRect.width / 2;
    const titleCenterY = titleRect.top + titleRect.height / 2;

    // 计算鼠标相对于标题中心的角度（连续值）
    const angleX = (e.clientY - titleCenterY) / 50;
    const angleY = (titleCenterX - e.clientX) / 50;

    // 应用3D旋转（连续变化）
    this.title.style.transform = `perspective(1000px) rotateX(${angleX}deg) rotateY(${angleY}deg)`;
  }

  // 动画循环（60fps连续更新）
  animate() {
    // 使用缓动函数平滑跟随（不是立即到达）
    const ease = 0.08; // 缓动系数，越小越平滑
    this.currentX += (this.mouseX - this.currentX) * ease;
    this.currentY += (this.mouseY - this.currentY) * ease;

    // 更新黑圈位置（连续平滑）
    this.circle.style.left = `${this.currentX}px`;
    this.circle.style.top = `${this.currentY}px`;

    // 检查黑圈是否在标题区域（实时检测）
    this.checkOverlap();

    // 继续下一帧（连续动画）
    requestAnimationFrame(() => this.animate());
  }

  // 检查黑圈与标题的重叠（连续检测）
  checkOverlap() {
    const circleRect = this.circle.getBoundingClientRect();
    const titleRect = this.title.getBoundingClientRect();

    // 计算重叠区域
    const overlap = this.calculateOverlap(circleRect, titleRect);

    if (overlap > 0) {
      // 根据重叠位置计算进度（连续值 0-1）
      const progress = (this.currentX - titleRect.left) / titleRect.width;

      // 根据进度显示对应的中文（连续过渡）
      const textIndex = Math.min(
        Math.floor(progress * this.chineseTexts.length),
        this.chineseTexts.length - 1
      );

      const newText = this.chineseTexts[textIndex];
      if (newText !== this.currentText) {
        // 文字变化时，淡出旧文字，淡入新文字
        this.fadeOutText(() => {
          this.currentText = newText;
          this.circle.querySelector('.text').textContent = newText;
          this.fadeInText();
        });
      }
    } else {
      // 移出标题区域时，淡出文字
      if (this.textOpacity > 0) {
        this.fadeOutText();
      }
    }
  }

  // 淡入效果（连续过渡）
  fadeInText() {
    const textEl = this.circle.querySelector('.text');
    textEl.style.transition = 'opacity 0.2s ease';
    textEl.style.opacity = '1';
    this.textOpacity = 1;
  }

  // 淡出效果（连续过渡）
  fadeOutText(callback) {
    const textEl = this.circle.querySelector('.text');
    textEl.style.transition = 'opacity 0.2s ease';
    textEl.style.opacity = '0';
    this.textOpacity = 0;
    if (callback) {
      setTimeout(callback, 200);
    }
  }
}

// 初始化
const magicCircle = new MagicCircle();
document.addEventListener('mousemove', (e) => magicCircle.onMouseMove(e));
magicCircle.animate(); // 启动连续动画循环
```

1. **黑圈跟随**：使用 `requestAnimationFrame` + 缓动函数实现平滑跟随，不是 CSS transition

// 数字计数器动画
function animateCounter(element, target, duration = 1500) {
  let start = 0;
  const increment = target / (duration / 16);

  function update() {
    start += increment;
    if (start >= target) {
      element.textContent = target;
      return;
    }
    element.textContent = Math.floor(start);
    requestAnimationFrame(update);
  }

  // 使用 IntersectionObserver 触发
  const observer = new IntersectionObserver((entries) => {
    if (entries[0].isIntersecting) {
      update();
      observer.disconnect();
    }
  });

  observer.observe(element);
}

function toggleCard(card) {

  } else {
    details.style.maxHeight = details.scrollHeight + 'px';

  }
}
